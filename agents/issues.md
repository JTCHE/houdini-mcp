# Issues

Issues and features live as specs in an Obsidian base, not in this repo.

**Vault path:** `<value of OBSIDIAN_VAULT_PATH in @.env.obsidian>/side projects/Houdini/HoudiniMCP — Fork/HoudiniMCP — Fork.base`

## Spec format

Frontmatter: `Type` (Issue | Feature), `Area`, `Status` (Open | Closed),
`Priority` (P1 | P2 | P3).

Body: one short paragraph. Name the file and the behaviour. State the decision
to make. No code blocks, no steps, no history.

## Status

When you commit work that closes a spec, and the user confirms it is complete,
set `Status: Closed` in that spec.
